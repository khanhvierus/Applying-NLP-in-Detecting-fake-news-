## Applying-NLP-in-Detecting-fake-news
### Project overview: 
Explore important & exciting facts around the dataset , the main goal is building models to detect(classify) true and fake news. The dataset includes different types of articles on different topics, however, the majority of articles focus on political topics and world news.
### Data and tools used: 
- Data : fake-news-detection-datasets from Kaggle
- Tool : Python
- Models applied : Logistic Regression , Linear SVC
- Main libraries that need to be installed : pandas , numpy , matplotlib , seaborn , scikit-learn ,...
